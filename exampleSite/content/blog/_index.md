The blog section demonstrates the theme's article cards, date and reading-time
metadata, tags, categories, and cover images. It is intentionally separate from
the documentation tree so you can compare both content types in one site.

{{< admonition type="note" title="Blog mode" >}}
Set `themeMode = "blog"` in `hugo.toml` to render the bento post feed on the
home page. The articles on this page remain available in both modes.
{{< /admonition >}}
