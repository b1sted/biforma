This nested section contains the first steps for a new site. Its pages are
grouped under **Fundamentals** in the sidebar and on the section page.

{{< admonition type="note" title="Prerequisites" >}}
You need Hugo Extended 0.156.0 or newer. Node.js is only required if you want to
build the Pagefind search index or use the optional build-time rendering
scripts.
{{< /admonition >}}
