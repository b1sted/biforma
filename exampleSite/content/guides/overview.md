The guides are split into two nested sections:

| Section | What it covers | Start here |
|:--------|:---------------|:-----------|
| **Getting Started** | Installation, configuration, and content structure | [Installation](/guides/getting-started/installation/) |
| **Advanced** | Customization, the feature showcase, and deployment | [Customization](/guides/advanced/customization/) |

## Reading order

1. Install Hugo and create a site.
2. Add the theme and copy the example configuration.
3. Organize content into sections and groups.
4. Customize colors, navigation, and search.
5. Build and deploy the generated `public/` directory.

{{< admonition type="tip" title="Shortcut" >}}
If you only want to see what the theme can render, jump straight to the
[Feature Showcase](/guides/advanced/feature-showcase/).
{{< /admonition >}}
