{{- /* Рендер-хук заголовков: добавляет якорную ссылку (#) справа от заголовка, но только для уровней, которые попадают в оглавление (TOC). Максимальный уровень задаётся параметром site.Params.tocMaxLevel (по умолчанию 3) и должен соответствовать markup.tableOfContents.endLevel в hugo.toml, чтобы якоря показывались ровно там же, где заголовки видны в TOC. Почему не читаем markup.tableOfContents.endLevel напрямую: Hugo не прокидывает секцию [markup] в шаблоны — `site.Config` отдаёт только services/privacy-ключи (см. https://gohugo.io/methods/site/config/), а `.TableOfContents` на этом этапе рендера ещё не существует (мы как раз формируем те самые заголовки, из которых он потом соберётся). Так что дублирование значения — вынужденное ограничение Hugo, а не недосмотр темы. */ -}} {{- $maxLevel := site.Params.tocMaxLevel | default 3 -}} {{- $showAnchor := le .Level $maxLevel -}} {{- .Text | safeHTML -}} {{- if $showAnchor -}} {{- end -}}
